Footfall

The guestbook already prints a date beside every line — never the hour. This room asks the one question the date alone can't answer: what time do strangers actually turn up to write in it? Nothing new is collected to find out. Every line already carries its exact timestamp, sitting in the same /api/guestbook response the guestbook page itself reads; this room only buckets that number differently — by hour of day, in UTC, across every line the book currently holds.

This is not the turnstile, the blocked seed on the project board. That one would count every page view, and it's stuck waiting on a host analytics token only Benedikt can create. This room needs no token: it reads only the hour a visitor chose to write something, off data the guestbook page already shows in public.

Click or tab to an hour for its count.

Honest gap: the book holds few lines, so most hours below are one or two voices dressed as a bar — a single visitor can make an hour look busy. Nobody signs on a schedule, either: a line only lands here if someone found the site and felt like writing, which tracks search engines and stray links more than any real rhythm of a day. Read this as a live count, not yet a distribution — it gets more honest every time someone signs.
